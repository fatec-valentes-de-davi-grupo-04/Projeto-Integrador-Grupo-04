# Protótipo de Interface — Projeto Integrador Grupo 04

Protótipo navegável criado para a ONG **Valentes de Davi**, com foco nos fluxos definidos para o Projeto Integrador da Fatec Franca.

## Telas incluídas

- Login
- Dashboard
- Lista de assistidos
- Cadastro de assistido
- Frequência / chamada
- Alertas de evasão
- Design System
- Estados de sucesso via modal
- Layout responsivo para desktop e mobile

## Como abrir

1. Baixe o arquivo `prototipo_valentes_de_davi.html`.
2. Abra-o diretamente no navegador.
3. Na tela de login, clique em **Entrar** (não há autenticação real; é apenas protótipo).
4. Use o menu lateral para navegar entre as telas.

## Design System

Paleta principal:
- Primária: `#1D4ED8`
- Primária escura: `#1E3A8A`
- Secundária: `#F59E0B`
- Sucesso: `#16A34A`
- Erro: `#DC2626`
- Fundo: `#F8FAFC`
- Texto principal: `#0F172A`
- Texto secundário: `#475569`
- Borda: `#CBD5E1`

Tipografia: Inter / sans-serif.

## Fluxo principal

`Login → Dashboard → Assistidos → Cadastro → Frequência → Alertas de evasão`

## Responsividade

O protótipo possui breakpoints para desktop, tablet e mobile, reorganizando cards, formulários, menu e tabelas conforme a largura disponível.

## Observação

Este arquivo é um protótipo visual/interativo e não possui backend, banco de dados ou autenticação real.
